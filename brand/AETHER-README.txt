FIRST TIME SETUP:

  1. Plug in USB drive
  2. Run START.sh (Mac/Linux) or START.bat (Windows)
  3. Choose option 3 (Configure Providers)
  4. Enter your API key or use offline models
  5. Choose option 1 (Dashboard)
  6. Start building!
